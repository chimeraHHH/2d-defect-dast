# PRB manuscript source

`main.tex` is the active manuscript and `main.pdf` is its compiled preview.
The paper uses the APS `prb` REVTeX 4.2 profile and is prepared as a *Physical
Review B* Regular Article.

Numerical Results, Discussion, and Conclusion content is exposed only when
`generated/results_ready.tex` exists. The current gate is present. The values in
`generated/results_macros.tex` come from the existing result pipeline;
`prb_context_macros.tex` exposes two pre-existing incorporation-class summaries
that the independent numeric audit checks directly against the archived group
errors. If the readiness file is absent, the manuscript deliberately omits
numerical claims rather than substituting historical values.

Evidence inputs:

- `../artifacts/prm_protocol_v2/` for the dataset audit and split definitions.
- `../artifacts/prm_assets/manifest.json` for initialization provenance.
- `../artifacts/prm_results/` for validated metrics and operation records.
- `../configs/prm/` for resolved model and training configurations.

Main Figs. 1--3 are the user-supplied schematics recorded in
`review/manual_figure_manifest.json`; main Figs. 4 and 5 are the transfer and
retrospective-reranking figures generated by
`../scripts/prm_make_result_assets.py`. The protocol overview is Supplemental
Fig. S1, and the AutoFigure editor-only factorial derivative is Supplemental
Fig. S2 under `review/autofigure_edit_manifest.json`. Internal UQ and the
legacy descriptive heterogeneity plot are Supplemental Figs. S3 and S4.
Scientific values and data geometry must not be changed during presentation
editing. The reserved G3 physical-error map is not included until its repaired
OOF evidence gate passes.

Verify the paper-facing numbers and evidence hashes from the repository root:

```bash
python3 scripts/prm_verify_paper_numbers.py --output /tmp/prb_numeric_audit.json
```

Build from this directory with:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
latexmk -pdf -interaction=nonstopmode -halt-on-error supplement.tex
```

Tectonic is an equivalent fallback when `latexmk` is unavailable:

```bash
tectonic --keep-logs --keep-intermediates main.tex
tectonic --keep-logs --keep-intermediates supplement.tex
```

For initial PRB submission, upload `main.pdf` as the manuscript and
`supplement.pdf` as a separate Supplemental Material file. The tracked source
archive is a reproducibility copy, not the initial manuscript upload. The cover
letter draft and Supplemental Material description are `cover_letter.md` and
`README.TXT`.

The remaining author-controlled blockers are the verified author order and
affiliations, corresponding-author contact and ORCID, final funder wording,
conflict and submission-history declarations, rights-holder-approved licenses,
and a versioned archival repository citation with a persistent identifier.
